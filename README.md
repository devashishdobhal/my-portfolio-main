# Devashish Dobhal Portfolio

Responsive portfolio built with React, Vite, CSS, Three.js, and resume-backed content.

## What's Included

- Personal details from Devashish Dobhal's resume.
- LinkedIn link: `linkedin.com/in/devashish-dobhal-52697b370`.
- GitHub link and project cards from `github.com/devashishdobhal`.
- Resume download in `public/Devashish_Dobhal_Resume.docx`.
- Experience section for LG internship, UIT ethical hacking training, and education.
- Skills, certifications, strengths, contact links, and animated 3D hero background.

## Run Locally

```bash
npm.cmd install
npm.cmd run dev
```

## Production Build

```bash
npm.cmd run build
npm.cmd run preview
```

Production files are generated in `dist/`.

## Customize

Main content lives here:

```text
src/data/portfolio.js
```

Main UI files:

```text
src/App.jsx
src/App.css
src/components/Scene3D.jsx
```

Resume asset:

```text
public/Devashish_Dobhal_Resume.docx
```
